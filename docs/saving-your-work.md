# Saving your work

At the end of every day, in GitHub Desktop:

1. Bottom left, type what you did — *"added my questions"*, *"made the scoring work"*
2. Click **Commit to main**
3. Click **Push origin** (top bar)

Two minutes. That's the whole thing.

**Ignore the branch dropdown.** Everything goes on `main` this week.

---

## The button that will save you

**Changes → right-click the file → Discard changes.**

You're going to let Claude edit your file, and at some point it'll change something you didn't want and you won't know what. Discard changes puts the file back to your last commit, instantly. That's why we commit every day — so there's always a recent point to fall back to.

This is the actual reason git exists. It's undo that survives closing your laptop.

---

## Reading what changed

The **Changes** tab in GitHub Desktop shows exactly what's different since your last commit — green lines were added, red lines were removed.

Get in the habit of glancing at it before you commit, especially after Claude has edited something. If you don't recognise what's there, that's rule 4 talking: discard it and ask again, more simply.

---

## Three words you'll see

- **Commit** — save a snapshot of your work, with a note about what you did. Local to your laptop.
- **Push** — send your commits up to GitHub, so they're backed up and visible online.
- **Discard changes** — throw away edits you haven't committed, back to your last snapshot.

That's all the git you need this week. There is a great deal more and none of it helps you yet.
